# **Ames Housing Price Prediction Machine Learning Project**

## Project Overview

This project focuses on predicting residential property prices using the Ames Housing Dataset through Machine Learning techniques.

## Project Objective

To develop a predictive model that estimates house prices based on selected property features.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Methodology

1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Data Cleaning and Preprocessing
4. Handling Missing Values
5. Data Encoding
6. Feature Selection (X and Y Splitting)
7. Train-Test Splitting
8. Feature Scaling
9. Linear Regression Model Building
10. Price Prediction

## Algorithm

Linear Regression

## Conclusion

This project demonstrates the application of Linear Regression to predict residential property prices using the Ames Housing Dataset.
